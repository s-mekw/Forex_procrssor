## 📊 技術詳細

### RCI期間設定
- **短期RCI（1分足）**: [9, 13, 24, 33, 48, 66, 108]
- **長期RCI（5分足）**: [24, 33, 48, 66, 108]
  - 120期間 → 24期間（5分足）
  - 165期間 → 33期間（5分足）
  - 240期間 → 48期間（5分足）
  - 330期間 → 66期間（5分足）
  - 540期間 → 108期間（5分足）

### データフロー
1. RealtimePipelineが1分足データを受信
2. TimeframeConverterが1分足を5分足にリサンプリング
3. MultiTimeframeAnalyzerが短期・長期RCIを並列計算
4. 結果を統合してタイムスタンプで整列
5. 後続処理に統合データを渡す

## 🎯 主要な決定事項
- Polarsの`group_by_dynamic`を使用して効率的なリサンプリングを実施
- 5分足バーの確定待ち処理を実装（データ不足時の処理遅延対応）
- RCICalculatorEngineの既存機能を活用し、コード重複を最小化
- パイプラインの責務分離を明確化（データフロー管理と分析処理の分離）

## ⚠️ リスクと対策
- **リスク**: リサンプリング時のメモリ使用量増加
  - **対策**: チャンクベースの処理とLazyFrame活用
- **リスク**: 5分足バー確定時の遅延
  - **対策**: 未完成バーのプレビュー機能を実装
- **リスク**: タイムスタンプの不整合
  - **対策**: 明示的なタイムゾーン管理とアライメント処理
